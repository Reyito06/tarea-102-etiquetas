102 Etiquetas HTML

Lista de 102 etiquetas HTML con explicaciones y ejemplos sencillos.

1. Etiqueta html

Descripción: Contiene toda la página web.

Ejemplo: <html lang="es">...</html>

Elemento adicional: Es la etiqueta principal del documento.

2. Etiqueta head

Descripción: Guarda información sobre la página.

Ejemplo: <head>...</head>

Elemento adicional: No contiene el contenido principal visible.

3. Etiqueta title

Descripción: Define el título que aparece en la pestaña del navegador.

Ejemplo: <title>Mi página</title>

Elemento adicional: Se coloca dentro de head.

4. Etiqueta meta

Descripción: Configura información de la página.

Ejemplo: <meta charset="UTF-8">

Elemento adicional: Ayuda a mostrar correctamente los caracteres.

5. Etiqueta link

Descripción: Conecta la página con otro archivo.

Ejemplo: <link rel="stylesheet" href="estilos.css">

Elemento adicional: Se usa frecuentemente para conectar CSS.

6. Etiqueta style

Descripción: Permite escribir estilos para cambiar la apariencia.

Ejemplo: <style>p { color: blue; }</style>

Elemento adicional: Se utiliza para escribir CSS dentro del documento.

7. Etiqueta body

Descripción: Contiene el contenido visible de la página.

Ejemplo: <body>Hola mundo</body>

Elemento adicional: Puede contener textos, imágenes y enlaces.

8. Etiqueta h1

Descripción: Crea el título principal.

Ejemplo: <h1>Mi página web</h1>

Elemento adicional: Es el nivel de encabezado más importante.

9. Etiqueta h2

Descripción: Crea un título de segundo nivel.

Ejemplo: <h2>Introducción</h2>

Elemento adicional: Sirve para dividir los temas.

10. Etiqueta h3

Descripción: Crea un título de tercer nivel.

Ejemplo: <h3>Primer tema</h3>

Elemento adicional: Se usa para organizar subtítulos.

11. Etiqueta h4

Descripción: Crea un título de cuarto nivel.

Ejemplo: <h4>Detalle</h4>

Elemento adicional: Ayuda a dividir un tema en partes pequeñas.

12. Etiqueta h5

Descripción: Crea un título de quinto nivel.

Ejemplo: <h5>Nota</h5>

Elemento adicional: Es menos importante que h4.

13. Etiqueta h6

Descripción: Crea un título de sexto nivel.

Ejemplo: <h6>Subnota</h6>

Elemento adicional: Es el nivel de encabezado más bajo.

14. Etiqueta p

Descripción: Permite escribir un párrafo.

Ejemplo: <p>Hola, bienvenidos.</p>

Elemento adicional: Se usa para escribir textos.

15. Etiqueta br

Descripción: Hace un salto de línea.

Ejemplo: Hola<br>Mundo

Elemento adicional: No necesita etiqueta de cierre.

16. Etiqueta hr

Descripción: Coloca una línea para separar contenido.

Ejemplo: <hr>

Elemento adicional: Ayuda a separar temas.

17. Etiqueta pre

Descripción: Muestra el texto respetando los espacios y saltos de línea.

Ejemplo: <pre>Hola mundo</pre>

Elemento adicional: Es útil para mostrar código.

18. Etiqueta blockquote

Descripción: Muestra una cita larga.

Ejemplo: <blockquote>La educación es importante.</blockquote>

Elemento adicional: Se utiliza para citas de otras fuentes.

19. Etiqueta ol

Descripción: Crea una lista numerada.

Ejemplo: <ol><li>Primero</li></ol>

Elemento adicional: Los elementos aparecen ordenados con números.

20. Etiqueta ul

Descripción: Crea una lista con viñetas.

Ejemplo: <ul><li>Manzana</li></ul>

Elemento adicional: Se utiliza cuando no se necesita numeración.

21. Etiqueta li

Descripción: Representa un elemento de una lista.

Ejemplo: <li>Naranja</li>

Elemento adicional: Se usa dentro de una lista.

22. Etiqueta dl

Descripción: Crea una lista de términos y explicaciones.

Ejemplo: <dl>...</dl>

Elemento adicional: Se combina con dt y dd.

23. Etiqueta dt

Descripción: Indica el término que se va a explicar.

Ejemplo: <dt>HTML</dt>

Elemento adicional: Se coloca dentro de dl.

24. Etiqueta dd

Descripción: Explica el término de una lista.

Ejemplo: <dd>Lenguaje para crear páginas web.</dd>

Elemento adicional: Normalmente va después de dt.

25. Etiqueta figure

Descripción: Agrupa una imagen o ilustración.

Ejemplo: <figure><img src="foto.jpg" alt="Foto"></figure>

Elemento adicional: Puede contener una descripción.

26. Etiqueta figcaption

Descripción: Agrega una descripción a una imagen o figura.

Ejemplo: <figcaption>Foto del paisaje</figcaption>

Elemento adicional: Se utiliza dentro de figure.

27. Etiqueta div

Descripción: Agrupa varios elementos de la página.

Ejemplo: <div>Contenido</div>

Elemento adicional: Ayuda a organizar el contenido.

28. Etiqueta a

Descripción: Crea un enlace a otra página o lugar.

Ejemplo: <a href="https://example.com">Visitar página</a>

Elemento adicional: El atributo href indica el destino.

29. Etiqueta span

Descripción: Permite seleccionar una parte pequeña de un texto.

Ejemplo: <span>Texto especial</span>

Elemento adicional: Se usa frecuentemente con CSS.

30. Etiqueta strong

Descripción: Indica que una palabra o frase es importante.

Ejemplo: <strong>Atención</strong>

Elemento adicional: Normalmente aparece en negrita.

31. Etiqueta em

Descripción: Da énfasis a una palabra o frase.

Ejemplo: <em>Muy importante</em>

Elemento adicional: Normalmente aparece en cursiva.

32. Etiqueta b

Descripción: Muestra un texto en negrita.

Ejemplo: <b>Texto resaltado</b>

Elemento adicional: Cambia la apariencia del texto.

33. Etiqueta i

Descripción: Muestra un texto en cursiva.

Ejemplo: <i>Palabra</i>

Elemento adicional: Puede usarse para términos especiales.

34. Etiqueta u

Descripción: Subraya un texto.

Ejemplo: <u>Texto subrayado</u>

Elemento adicional: Añade una línea debajo del texto.

35. Etiqueta s

Descripción: Muestra un texto que ya no es válido.

Ejemplo: <s>Precio anterior</s>

Elemento adicional: Normalmente aparece tachado.

36. Etiqueta small

Descripción: Muestra texto secundario más pequeño.

Ejemplo: <small>Nota importante</small>

Elemento adicional: Puede utilizarse para notas o aclaraciones.

37. Etiqueta mark

Descripción: Resalta una parte del texto.

Ejemplo: <mark>Palabra importante</mark>

Elemento adicional: Normalmente aparece con fondo amarillo.

38. Etiqueta del

Descripción: Indica que un texto fue eliminado.

Ejemplo: <del>Texto eliminado</del>

Elemento adicional: Normalmente aparece tachado.

39. Etiqueta ins

Descripción: Indica que se agregó un texto.

Ejemplo: <ins>Texto nuevo</ins>

Elemento adicional: Normalmente aparece subrayado.

40. Etiqueta sub

Descripción: Coloca un texto un poco más abajo.

Ejemplo: H<sub>2</sub>O

Elemento adicional: Se utiliza en fórmulas como H₂O.

41. Etiqueta sup

Descripción: Coloca un texto un poco más arriba.

Ejemplo: x<sup>2</sup>

Elemento adicional: Se utiliza para escribir potencias como x².

42. Etiqueta code

Descripción: Muestra un fragmento de código.

Ejemplo: <code>alert("Hola")</code>

Elemento adicional: Es útil para explicar programación.

43. Etiqueta kbd

Descripción: Representa una tecla del teclado.

Ejemplo: <kbd>Enter</kbd>

Elemento adicional: Ayuda a explicar qué tecla se debe presionar.

44. Etiqueta samp

Descripción: Muestra un resultado producido por un programa.

Ejemplo: <samp>Proceso terminado</samp>

Elemento adicional: Representa una salida de computadora.

45. Etiqueta var

Descripción: Representa una variable.

Ejemplo: <var>x</var>

Elemento adicional: Se usa en matemáticas y programación.

46. Etiqueta abbr

Descripción: Indica que una palabra es una abreviatura.

Ejemplo: <abbr title="Universidad Autónoma de Santo Domingo">UASD</abbr>

Elemento adicional: title permite indicar el significado completo.

47. Etiqueta cite

Descripción: Identifica el título de una obra.

Ejemplo: <cite>Don Quijote</cite>

Elemento adicional: Puede usarse para libros o películas.

48. Etiqueta q

Descripción: Marca una cita corta.

Ejemplo: <q>La práctica hace al maestro</q>

Elemento adicional: El navegador suele agregar comillas.

49. Etiqueta dfn

Descripción: Marca un término que se está definiendo.

Ejemplo: <dfn>Internet</dfn>

Elemento adicional: Se usa al explicar conceptos.

50. Etiqueta time

Descripción: Representa una fecha u hora.

Ejemplo: <time datetime="2026-10-28">28 de octubre de 2026</time>

Elemento adicional: Permite escribir fechas de forma organizada.

51. Etiqueta img

Descripción: Muestra una imagen.

Ejemplo: <img src="foto.jpg" alt="Mi foto">

Elemento adicional: src indica la imagen y alt la describe.

52. Etiqueta picture

Descripción: Permite elegir una imagen según el dispositivo.

Ejemplo: <picture>...</picture>

Elemento adicional: Puede contener source e img.

53. Etiqueta source

Descripción: Indica un archivo de imagen, audio o video.

Ejemplo: <source src="audio.mp3" type="audio/mpeg">

Elemento adicional: Se utiliza con picture, audio o video.

54. Etiqueta audio

Descripción: Permite reproducir sonido.

Ejemplo: <audio controls src="audio.mp3"></audio>

Elemento adicional: controls muestra los botones de reproducción.

55. Etiqueta video

Descripción: Permite reproducir un video.

Ejemplo: <video controls src="video.mp4"></video>

Elemento adicional: controls permite reproducir y pausar.

56. Etiqueta track

Descripción: Agrega subtítulos a un video.

Ejemplo: <track kind="subtitles" src="subtitulos.vtt" srclang="es" label="Español">

Elemento adicional: Se utiliza dentro de video o audio.

57. Etiqueta iframe

Descripción: Muestra otra página dentro de la actual.

Ejemplo: <iframe src="pagina.html" title="Otra página"></iframe>

Elemento adicional: Algunos sitios no permiten ser insertados de esta manera.

58. Etiqueta object

Descripción: Inserta un recurso externo, como un documento.

Ejemplo: <object data="documento.pdf" type="application/pdf"></object>

Elemento adicional: Puede utilizarse para mostrar archivos compatibles.

59. Etiqueta canvas

Descripción: Crea un espacio para dibujar con JavaScript.

Ejemplo: <canvas width="200" height="100"></canvas>

Elemento adicional: Se utiliza para gráficos y dibujos.

60. Etiqueta svg

Descripción: Permite crear figuras y dibujos vectoriales.

Ejemplo: <svg width="100" height="100">...</svg>

Elemento adicional: Se puede utilizar para crear figuras geométricas.

61. Etiqueta table

Descripción: Crea una tabla.

Ejemplo: <table>...</table>

Elemento adicional: Contiene filas y celdas.

62. Etiqueta caption

Descripción: Agrega un título a una tabla.

Ejemplo: <caption>Lista de estudiantes</caption>

Elemento adicional: Se coloca dentro de table.

63. Etiqueta thead

Descripción: Agrupa los encabezados de una tabla.

Ejemplo: <thead>...</thead>

Elemento adicional: Normalmente contiene los títulos de las columnas.

64. Etiqueta tbody

Descripción: Agrupa las filas principales de una tabla.

Ejemplo: <tbody>...</tbody>

Elemento adicional: Contiene los datos de la tabla.

65. Etiqueta tfoot

Descripción: Agrupa la parte final de una tabla.

Ejemplo: <tfoot>...</tfoot>

Elemento adicional: Puede contener totales o resúmenes.

66. Etiqueta tr

Descripción: Crea una fila en una tabla.

Ejemplo: <tr>...</tr>

Elemento adicional: Contiene celdas de encabezado o de datos.

67. Etiqueta th

Descripción: Crea una celda de encabezado.

Ejemplo: <th>Nombre</th>

Elemento adicional: Indica el título de una columna o fila.

68. Etiqueta td

Descripción: Crea una celda para colocar datos.

Ejemplo: <td>Bienvenido</td>

Elemento adicional: Se utiliza dentro de una fila.

69. Etiqueta colgroup

Descripción: Agrupa columnas de una tabla.

Ejemplo: <colgroup>...</colgroup>

Elemento adicional: Permite configurar columnas.

70. Etiqueta col

Descripción: Representa una o varias columnas de una tabla.

Ejemplo: <col span="2">

Elemento adicional: Se utiliza dentro de colgroup.

71. Etiqueta form

Descripción: Crea un formulario para introducir información.

Ejemplo: <form>...</form>

Elemento adicional: Puede contener campos y botones.

72. Etiqueta label

Descripción: Escribe el nombre de un campo del formulario.

Ejemplo: <label for="nombre">Nombre:</label>

Elemento adicional: Se puede relacionar con un campo mediante for e id.

73. Etiqueta input

Descripción: Crea un campo para escribir o seleccionar información.

Ejemplo: <input type="text" id="nombre">

Elemento adicional: type determina el tipo de campo.

74. Etiqueta button

Descripción: Crea un botón.

Ejemplo: <button>Enviar</button>

Elemento adicional: Puede ejecutar una acción.

75. Etiqueta select

Descripción: Crea una lista desplegable.

Ejemplo: <select>...</select>

Elemento adicional: Permite seleccionar una opción.

76. Etiqueta datalist

Descripción: Ofrece sugerencias para escribir en un campo.

Ejemplo: <datalist id="ciudades">...</datalist>

Elemento adicional: Se conecta con input mediante el atributo list.

77. Etiqueta optgroup

Descripción: Agrupa opciones relacionadas en una lista.

Ejemplo: <optgroup label="Frutas">...</optgroup>

Elemento adicional: Se utiliza dentro de select.

78. Etiqueta option

Descripción: Define una opción de una lista desplegable.

Ejemplo: <option value="rojo">Rojo</option>

Elemento adicional: Se usa dentro de select.

79. Etiqueta textarea

Descripción: Crea un campo para escribir varias líneas.

Ejemplo: <textarea>Escribe aquí</textarea>

Elemento adicional: Se utiliza para comentarios o mensajes largos.

80. Etiqueta output

Descripción: Muestra el resultado de un cálculo.

Ejemplo: <output>10</output>

Elemento adicional: Puede actualizarse mediante JavaScript.

81. Etiqueta progress

Descripción: Muestra el avance de una tarea.

Ejemplo: <progress value="60" max="100"></progress>

Elemento adicional: El ejemplo representa un avance del 60 %.

82. Etiqueta meter

Descripción: Muestra una medida dentro de un rango.

Ejemplo: <meter value="7" min="0" max="10">7 de 10</meter>

Elemento adicional: Puede representar una puntuación.

83. Etiqueta fieldset

Descripción: Agrupa campos relacionados de un formulario.

Ejemplo: <fieldset>...</fieldset>

Elemento adicional: Ayuda a organizar los datos.

84. Etiqueta legend

Descripción: Escribe el título de un grupo de campos.

Ejemplo: <legend>Datos personales</legend>

Elemento adicional: Se coloca dentro de fieldset.

85. Etiqueta details

Descripción: Crea una sección que se puede abrir y cerrar.

Ejemplo: <details>...</details>

Elemento adicional: Permite ocultar información hasta que se abra.

86. Etiqueta summary

Descripción: Escribe el título de una sección desplegable.

Ejemplo: <summary>Ver más</summary>

Elemento adicional: Se coloca dentro de details.

87. Etiqueta dialog

Descripción: Representa una ventana de diálogo.

Ejemplo: <dialog open>Hola</dialog>

Elemento adicional: Puede utilizarse para mostrar avisos o ventanas.

88. Etiqueta script

Descripción: Permite agregar código JavaScript.

Ejemplo: <script>alert("Hola");</script>

Elemento adicional: Puede agregar interactividad a la página.

89. Etiqueta noscript

Descripción: Muestra un mensaje cuando JavaScript no está disponible.

Ejemplo: <noscript>JavaScript no está disponible.</noscript>

Elemento adicional: Ofrece información alternativa al usuario.

90. Etiqueta template

Descripción: Guarda contenido que no se muestra inmediatamente.

Ejemplo: <template><p>Hola</p></template>

Elemento adicional: JavaScript puede utilizar ese contenido después.

91. Etiqueta header

Descripción: Representa la cabecera de una página o sección.

Ejemplo: <header>Mi sitio web</header>

Elemento adicional: Puede contener títulos o logotipos.

92. Etiqueta footer

Descripción: Representa el pie de una página o sección.

Ejemplo: <footer>Todos los derechos reservados</footer>

Elemento adicional: Puede contener información de contacto.

93. Etiqueta nav

Descripción: Agrupa enlaces para navegar por una página.

Ejemplo: <nav><a href="#inicio">Inicio</a></nav>

Elemento adicional: Se usa normalmente para los menús.

94. Etiqueta main

Descripción: Contiene el contenido principal de la página.

Ejemplo: <main>Contenido principal</main>

Elemento adicional: Normalmente se utiliza una sola vez como contenido principal.

95. Etiqueta section

Descripción: Divide el contenido en secciones por tema.

Ejemplo: <section><h2>Servicios</h2></section>

Elemento adicional: Ayuda a organizar la información.

96. Etiqueta article

Descripción: Representa un contenido que puede entenderse por sí solo.

Ejemplo: <article>Noticia del día</article>

Elemento adicional: Puede utilizarse para noticias o publicaciones.

97. Etiqueta aside

Descripción: Contiene información complementaria.

Ejemplo: <aside>Dato relacionado</aside>

Elemento adicional: Puede mostrar notas o información secundaria.

98. Etiqueta address

Descripción: Presenta información de contacto.

Ejemplo: <address>Correo: ejemplo@correo.com</address>

Elemento adicional: Puede incluir un correo o una dirección.

99. Etiqueta hgroup

Descripción: Agrupa un título con un subtítulo relacionado.

Ejemplo: <hgroup><h1>Mi sitio</h1><p>Bienvenidos</p></hgroup>

Elemento adicional: Ayuda a presentar un título y su complemento.

100. Etiqueta menu

Descripción: Representa una lista de opciones o comandos.

Ejemplo: <menu><li>Guardar</li></menu>

Elemento adicional: Contiene elementos de lista.

101. Etiqueta wbr

Descripción: Indica dónde se puede dividir una palabra larga si hace falta.

Ejemplo: super<wbr>palabra

Elemento adicional: El navegador hace el salto solo cuando lo necesita.

102. Etiqueta bdi

Descripción: Separa un texto cuya dirección de escritura puede ser diferente.

Ejemplo: <bdi>اسم</bdi>

Elemento adicional: Es útil al mezclar idiomas que se escriben en direcciones distintas.

Fin de la lista de las 102 etiquetas HTML.
